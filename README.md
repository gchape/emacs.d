# My dot emacs

This is my personal Emacs configuration, and custom settings tailored for programming with JavaScript, React, CSS, HTML, and Org mode. 

*It's like a well-organized toolbox—if only Emacs could also fix my procrastination!*

![Screenshot_20250113_020242](https://github.com/user-attachments/assets/3ffdcfb3-f240-4264-8964-632284619bd0)

## Features

- **User Interface**:
  - Doom modeline for a minimal status bar.
  - Gruvbox Dark Hard theme.
  - Centaur Tabs for easy navigation with tabs.
  - Neotree file explorer (F8 to toggle).
  - Corfu for autocompletion.

- **Languages**:
  - JavaScript and JSX support with `js2-mode` and `rjsx-mode`.
  - JSON support with `json-mode`.
  - LSP (Language Server Protocol) integration for enhanced coding assistance.
  - Prettier for automatic code formatting.
  - Emmet for faster HTML and CSS writing.

- **Org Mode**:
  - Custom setup for Org mode with support for JavaScript code blocks.

- **Miscellaneous**:
  - Auto-save on idle with `super-save`.
  - Electric pair mode for automatic pairing of brackets and quotes.
